  Capacities, service limits and common values for a UK Series 1 high-power RX-8.

Values here are for the 2005 UK high-power car unless noted. Service-fill quantities are starting quantities: set the final level using the dipstick or filler opening as applicable.

## Vehicle and engine

| Item | Specification |
| --- | --- |
| Engine | 13B-MSP Renesis, two rotor, six-port high-power |
| Gearbox | Y16M-D six-speed manual |
| Final drive | 4.444:1 |
| Differential | Factory torque-sensing Super-LSD |
| Standard wheel | 18 × 8JJ, ET50, 5 × 114.3 mm |
| Tyre | 225/45R18 91W |
| Cold tyre pressure | 220 kPa / 2.2 bar / 32 psi, front and rear |

## Fluids and capacities

| System | Specification | Quantity |
| --- | --- | ---: |
| Engine oil, drain and refill | 5W-30 is the Mazda European reference ( I use 10W-40 Semi-Synthetic) | 3.3 L |
| Engine oil, with filter | As above; confirm on dipstick | 3.5 L |
| Engine oil, overhauled engine | Initial fill after overhaul | 4.7 L |
| Engine oil, total dry twin-cooler system | Not a routine service fill | 6.7 L |
| Cooling system | Ethylene-glycol coolant and demineralised water; use premixed FL22 where the cap/neck is marked FL22 | 9.8 L total |
| Y16M-D gearbox | SAE 75W-90, API GL-4 or GL-5 | 1.75 L |
| Differential | SAE 90, 80W-90 or 75W-90, API GL-5 | 1.2–1.4 L |
| Brake hydraulic system | DOT 3, SAE J1703 / FMVSS 116 | Fill to reservoir mark |
| Clutch hydraulic system | DOT 3 or DOT 4 for the UK specification | Fill to reservoir mark |
| Fuel tank | Premium unleaded petrol (>=98 Octane) | Approximately 61 L |

## Common service values

| Item | Value |
| --- | --- |
| Leading spark plug | NGK RE8A-L standard; RE7A-L hotter factory option. RE7C-L is fitted on this car. |
| Trailing spark plug | NGK RE9B-T |
| Plug gap | 1.05–1.15 mm; do not bend the iridium electrodes to adjust |
| Spark-plug torque | 12.8–17.7 Nm |
| Wheel-nut torque | 88–118 Nm, clean dry seating faces |
| Oil pressure reference | 500 kPa / 5.0 bar at 3,000 rpm and 100 °C oil, high-power engine |
| Fuel pressure, running | 375–450 kPa / 3.75–4.50 bar |
| Fuel pressure after five minutes | At least 200 kPa / 2.0 bar |
| Thermostat | Starts opening 80–84 °C; fully open at 95 °C |
| Cooling fans, rising temperature | Both low at 97 °C; both high at 101 °C |
| Cooling fans, falling temperature | High to low at 98 °C; low to off at 94 °C |
| Compression at 250 rpm | 830 kPa standard; 680 kPa minimum |
| Maximum compression spread | 150 kPa within one rotor; 100 kPa front-to-rear |
| Gearbox ratios | 3.760 / 2.269 / 1.645 / 1.187 / 1.000 / 0.843; reverse 3.564 |
